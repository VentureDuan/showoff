# 个人网站首版

## 已确认设计

- 使用 A「个人名片」Bento 布局，默认白底、橙黄点缀，支持明暗切换与轻量悬停反馈。
- 面试官可以快速了解个人定位、代表项目、工作经历、文章与学习札记。
- 中文内容，技术术语保留原文；不做双语。
- 项目具有独立详情页，明确背景、职责、方案与结果复盘。
- Markdown 文章与札记支持统一搜索、标签筛选、自动目录与代码高亮。
- 不包含评论、留言、登录、访问统计与 AI 对话。
- Astro 静态生成，不要求后台服务。

## 内容来源

- 主简历：`D:\workspace\Interview\resumes\段锦涛-AI应用开发工程师-2026-10-14.md`。
- 博客：用户指定 `D:\workspace\blog`。复制迁移，不修改原目录。
- 手机号未放入站点，保留公开职业邮箱与 GitHub 入口。
- 原博客 `责任链模式.md` 实际介绍 Option 模式，网站按正文命名。
- 两篇缺少原始日期的内容标记为收录日期，不声称是创作日期。
- `如何开始刷LeetCode.md` 归为学习札记，其余两篇归为技术文章。

## 实现边界

本轮只完成本地网站，不部署、不提交、不推送。
真实头像缺失，使用姓名首字；简历提供网页、Markdown 下载与浏览器打印。
博客内容是历史笔记，迁移不代表完成技术校对。

## 后续维护

直接修改 `src/content/posts/`、`src/content/projects/` 和 `src/data/profile.ts`。
