## 背景与问题

云游戏系统的排障线索分散在日志、数据库、消息与实例中。调查者需要在多个服务和工具之间切换，再把结果交给研发继续处理。

Ask-Venture 是适配 Codex、Claude Code、ZCode 等 Coding Agent 的内部排障插件。

## 我的职责

独立完成用户调研、需求定义、设计开发、内部推广及迭代。

## 关键方案

- 整合 MySQL、ES、Kafka、Temporal、Apollo 和远程取证 MCP，以领域 Skills 组织业务知识，关联代码、运行时与业务上下文。
- 基于 Skill 的 Gateway 先检查环境、目标和现象；信息不足时澄清，按领域路由并按需加载知识。
- 生产 MySQL 使用只读账号，远程变更遵守独立授权边界。
- 通过 handoff Skill 导出 Markdown 排障上下文，让研发在已有证据上继续修复与验证。

## 结果与复盘

在一次“LS 成功但 SDK launch 超时”的调查中，关联实例日志、Kafka 消息与消费位点、服务日志及代码，定位请求地址错误，并交接研发修复。

这个项目的重点是帮助调查者完成问题定位与研发交接。定位到原因、完成代码修复与验证线上恢复是不同阶段，不能用一次工具调用成功替代完整结果。
