## 背景与问题

云游戏实例需要完成准备、运行、维护等生命周期管理，并在实例内协同处理游戏包、服务与用户存档。

## 我的职责

主导并核心负责实例管理、服务包管理、平台 Agent 与业务 Agent 的从零建设、持续迭代与维护。

## 关键方案

- 建设实例生命周期批处理，以及准备阶段 Agent、串流服务的安装与更新能力。
- 建设平台 Agent 的服务状态管理与实例监控。
- 建设业务 Agent 的游戏包、内容分发、多开、存档和带宽采集能力。
- 参与远程取证 Agent 的部署链路。

## 结果与复盘

形成覆盖集中管理服务与实例内 Agent 的工程实践。区分服务状态、业务状态与回调语义，是理解和排查跨组件问题的基础。
