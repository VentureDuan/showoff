## 背景与问题

云游戏启动与串流涉及多个阶段，需要按版本、时段、机房等维度观察变化，再关联发布、灰度和网络证据。

## 我的职责

负责全部模块的设计与实现，已落地使用。

## 关键方案

- 将固定 SQL 与固定 Python 脚本封装为参数化分析能力，由程序完成查询、聚合和变化量计算。
- LLM 理解业务上下文并选择后续查询，下钻、补充证据并生成解释；报表数值来自确定性计算层。
- 结合内部监控、MySQL 与分析查询平台，按版本、时段和机房下钻，形成可复核的调查报告。
- 报告推送至 Webhook，由下游完成邮件或企微通知。

## 结果与复盘

将数据分析、证据下钻与调查报告交付组织为完整流程。计算与解释职责分离，减少让 LLM 自由生成数值的风险。

确定性计算并不自动证明源数据、统计口径或归因正确；Webhook 接收也不等于下游通知已送达。这些边界需要分别验证。
