# Bento 视觉原型（非生产实现）

问题：白底、橙黄点缀的个人网站，哪种信息层级适合快速了解与深入阅读？

运行：`npm run prototype`，打开 http://127.0.0.1:4321/?variant=A 。无第三方依赖。

- A：个人名片。个人介绍与姓名卡并列，随后展示项目、经历与文章。
- B：作品橱窗。全幅宣言与大项目卡优先，个人简介作为侧卡。
- C：成长工作台。个人资料侧栏与内容区域并列，文章采用开放列表。
- 底部按钮或左右方向键切换布局，URL 保存布局选项。
- 支持明暗切换、移动布局、示例文章列表与搜索筛选、文章与项目详情。
- 所有经历、项目与文章都是标注过的示例；简历、联系方式尚未接入。
- 纯 HTML/CSS/JS 用于快速验证，不代表正式网站框架选择；主题不持久保存。

尚待用户评价布局，不能记录为已验证设计决策。正式实现应根据反馈重新组织。
