# 图标与图片来源

- GitHub 图标：Simple Icons，https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg
- 微信图标：Simple Icons，https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg
- 图标保存在 `public/icons/`，以本地 SVG 显示，不请求外部图标服务。
- 微信二维码：用户提供的 `src/content/微信二维码.jpg`，原图引用，不裁剪或重绘二维码。
